# FYP_Dengue_Risk_Prediction

This project scaffold contains the directory structure for a dengue risk prediction framework with three modules:
- Module 1: forecasting
- Module 2: classification
- Module 3: spatial analysis

## Structure

- data/ for raw, processed, and feature data
- src/ for preprocessing, modeling, and dashboard code
- notebooks/ for exploration notebooks
- models/ for trained artifacts
- outputs/ for figures, metrics, and reports

## Getting started

1. Install dependencies with `pip install -r requirements.txt`
2. Run the orchestration script with `python run_all.py`
